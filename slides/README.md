# ERS Brazil — Sample Slides

A 7-slide sample deck in the style of the **Apresentação Comercial 2026** (the client's
primary, most up-to-date work reference). Built on `deck-stage.js` (1920×1080, auto-scaling,
keyboard nav, thumbnail rail, print-to-PDF).

Open `index.html`. Slides are static `<section>` elements inside `<deck-stage>` so headings
can be edited directly.

## Slide types (reusable layouts)
1. **Capa / Title** — Bebas kicker + giant Bebas headline, S-pattern watermark, logo + `@ersbrazil`.
2. **Sobre / About** — intro paragraph + big Bebas stat row.
3. **Serviços** — 3 service cards (the three pillars: ITAD/IT Asset Disposition, Reciclagem, Logística Reversa) on a green band, numbered with bullet lists.
4. **Diferenciais** — icon + title + description grid (Lucide icons).
5. **Certificações** — certification ledger (R2v3, ISO 9001/14001/45001/27001) + e-waste badge.
6. **Cases** — two-column metrics (TJSP ITAD · Logística Reversa) with big Bebas numbers.
7. **Encerramento / Closing** — `DO WHAT'S RIGHT` lockup + logo.

## System
- Background: petrol (`#043035`); one optional light variant (`.light`).
- Display: Bebas Neue for kickers, headlines, stat numbers; Montserrat for everything else.
- Accents: green for emphasis/numbers, orange for kickers/bullets.
- Every slide carries the white logo (bottom-left) and `@ersbrazil` handle (bottom-right),
  matching the source deck's footer treatment.
